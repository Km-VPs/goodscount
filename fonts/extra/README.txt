Optional Lao fonts for GoodsCount
=================================
Put these files in this folder to unlock the two extra Lao font choices in Settings:

  SaysetthaOT.ttf   (or .woff2)   -> "Saysettha OT"
  HinSiew.ttf       (or .woff2)   -> "Hin Siew"

Keep the file names exactly as above. Only use font files you are allowed to redistribute.
Without these files the app still works: it uses Noto Sans Lao / Phetsarath OT (embedded).
